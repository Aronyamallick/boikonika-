# মল্লিক বুক হাউজ — ডেস্কটপ অ্যাপ (Windows)

এটি মূল ওয়েব অ্যাপ্লিকেশনের একটি **Electron (Chromium)** ডেস্কটপ র‌্যাপার। ফলে আপনি
কম্পিউটারে একটি আলাদা জানালায় (window) পুরো শপ সিস্টেম চালাতে পারবেন — ব্রাউজার খোলা-বন্ধ করার
ঝামেলা নেই। এটি ওয়েব অ্যাপের **সাথে সাথে একই ডাটাবেজ/সার্ভার** ব্যবহার করে, তাই মোবাইল, ওয়েব
আর কম্পিউটার — সব জায়গার ডাটা সবসময় একই থাকে।

## ১. আগে যা করতে হবে (একবার)

- ওয়েব অ্যাপটি যেকোনো হোস্টিংয়ে ইনস্টল করে চালু করুন (README-র ধাপ ১ অনুযায়ী)।
- নিচের ফাইলটিতে আপনার অ্যাপের ঠিকানা বসান:

  ```json
  // desktop/config.json
  {
    "appUrl": "https://your-domain.com/login.php"
  }
  ```

- (ঐচ্ছিক) অ্যাপ আইকন: `assets/img/icon-512.png` কে `desktop/assets/icon.png` নামে কপি করুন।
  ফাইল না থাকলেও অ্যাপ চলবে — শুধু ডিফল্ট আইকন দেখাবে।

## ২. ডেস্কটপ অ্যাপ চালানো ও ইন্সটলার তৈরি

`desktop/` ফোল্ডারে কমান্ড প্রম্পট (cmd / PowerShell) খুলে:

```bash
npm install
npm start        # ডেভ মোডে চালু হয় (দ্রুত পরীক্ষার জন্য)
npm run dist     # Windows ইন্সটলার (.exe) তৈরি হয় — dist/ ফোল্ডারে
```

> Node.js (v18+) ইন্সটল থাকতে হবে: https://nodejs.org

`dist/` ফোল্ডারে `Mallik Book House Setup x.x.x.exe` তৈরি হবে — এটি যেকোনো Windows
কম্পিউটারে ইন্সটল করে চালানো যাবে।

## ৩. এটি যা দেয়

- এক-ক্লিকে চালু — আলাদা অ্যাপের মতো দেখতে, ব্রাউজার ট্যাবের মতো নয়।
- `Ctrl+P` চাপলে সরাসরি OS প্রিন্ট ডায়ালগ (ইনভয়েস প্রিন্ট)।
- অ্যাপের বাইরের লিংক ডিফল্ট ব্রাউজারে খোলে; অ্যাপের ভেতরের নেভিগেশন সুরক্ষিত।
- সার্ভার ডাউন থাকলে বোধগম্য এরর মেসেজ দেখায়।
